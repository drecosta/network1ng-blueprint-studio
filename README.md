# NetworK1NG Blueprint Studio

A mobile-first architectural floor-plan editor with a metric SVG canvas, snapping, live room areas, touch gestures, and SVG/PNG export.

## Live site

https://drecosta.github.io/network1ng-blueprint-studio/

## Install as an app

Open the live site on your phone, then choose **Install app** in the Export panel. On iOS, use the browser share menu and choose **Add to Home Screen**. The app works offline after the first visit.

## Features

- Pan, zoom, pinch, drag, resize, and rotate
- Walls, rooms, doors, windows, and furniture objects
- Exact wall length and thickness editing with Apply/Cancel
- Grid, corner, edge, and alignment snapping
- Live total floor area in square metres
- Undo/redo and project presets
- Branded SVG and PNG exports
- Installable PWA with offline support
